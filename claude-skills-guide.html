Как создать свои навыки Claude без программирования

Не нужно собирать пять отдельных ИИ-агентов. Можно сделать пять навыков под свои задачи — и Claude будет работать по твоим инструкциям.

2 готовых промпта · 4 шага · без кода

Все вокруг говорят про ИИ-агентов. Но начать можно гораздо проще.

Навык (Skill) — это файл SKILL.md, в котором обычными словами описано, как именно ты выполняешь задачу. Claude сможет использовать эту инструкцию в подходящих запросах. И самое удобное: файл можно собрать из твоих ответов на интервью.

Ты просто рассказываешь Claude о своей работе — он помогает превратить это в понятную инструкцию.

01. Сначала попроси Claude взять интервью

Открой Claude, вставь промпт и отвечай на вопросы по одному. Никакого программирования.

Промпт №1 — интервью

Возьми у меня подробное интервью, чтобы изучить мою сферу деятельности, рабочие задачи и процессы. Выясни, чем я занимаюсь, как организована моя работа, какие задачи я выполняю и по каким принципам принимаю решения. Задавай вопросы по одному, уточняй детали и постарайся максимально глубоко разобраться в моей работе.

Обязательно выясни:
— с чего начинается каждая задача;
— что я делаю дальше и в каком порядке;
— какие инструменты использую;
— как выглядит готовый результат;
— где чаще всего возникают ошибки;
— какие правила нельзя нарушать.

Когда соберёшь информацию, предложи 3–5 отдельных навыков под мои задачи. Пока не создавай файлы.

Рассказывай как подруге: своими словами и на конкретных примерах.

02. Преврати ответы в навык

Когда интервью закончится, выбери одну задачу. Например, написание сценариев Reels. Отправь следующий запрос.

Промпт №2 — создание SKILL.md

На основе моего интервью создай готовый навык Claude для задачи «[НАЗВАНИЕ ЗАДАЧИ]».

Составь полноценный файл SKILL.md с корректным YAML frontmatter: name (латиницей, маленькими буквами через дефисы) и description (когда использовать этот навык).

Опиши:
1. Когда применять навык.
2. Какие данные нужны для начала.
3. Все шаги выполнения задачи.
4. Мои критерии качества.
5. Типичные ошибки и запреты.
6. Проверку результата перед сдачей.

Используй мои ответы, не придумывай факты. Если чего-то не хватает, уточни. Покажи полный текст SKILL.md и дай скачать файл, если это доступно.

03. Установи навык в Claude

1. Сохрани файл под названием SKILL.md.
2. При необходимости упакуй его в ZIP-архив.
3. Открой Claude → Settings → Capabilities → Skills.
4. Найди загрузку своего навыка и добавь файл или архив.

Если раздела Skills нет: доступность функции и названия пунктов могут отличаться в зависимости от версии Claude и тарифа.

04. Проверь на настоящей задаче

Напиши Claude: «Используй мой навык [название] и подготовь [задача]. Если не хватает данных, сначала задай вопросы. В конце проверь результат по критериям из навыка».

Если что-то не понравилось — попроси обновить инструкцию. Навык можно улучшать по мере работы.

Какие навыки можно сделать?

01. Идеи для Reels

Поиск тем, отбор вирусных механик и хуков.

02. Сценарии

Твоя структура, стиль и правила подачи.

03. Карусели и посты

Подача контента в твоём tone of voice.

04. Аналитика

Отчёты и выводы по одному шаблону.

Навык не делает Claude полностью автономным агентом: качество результата и выполнение задачи нужно проверять.
