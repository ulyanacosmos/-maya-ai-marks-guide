# Как создать свой навык Claude за 15 минут — без кода

**Один раз объясни Claude, как ты работаешь, — и сохрани эту инструкцию как навык (Skill).** Он сможет использовать её снова в подходящих задачах.

> Навык — это инструкция для Claude в файле `SKILL.md`. Это не отдельный ИИ-агент и не волшебная кнопка: результат всё равно стоит проверять.

## Шаг 1. Попроси Claude взять у тебя интервью

Открой [Claude](https://claude.ai/) и отправь этот промпт:

```text
Возьми у меня подробное интервью, чтобы изучить мою сферу деятельности, рабочие задачи и процессы. Выясни, чем я занимаюсь, как организована моя работа, какие задачи я выполняю и по каким принципам принимаю решения. Задавай вопросы по одному, уточняй детали и постарайся максимально глубоко разобраться в моей работе.

Особенно выясни:
— с чего начинается каждая задача;
— какие шаги я выполняю и в каком порядке;
— какие материалы и инструменты использую;
— по каким критериям оцениваю готовый результат;
— какие ошибки чаще всего возникают;
— что нельзя делать ни при каких условиях.

Пиши простым языком, без технических терминов. Когда соберёшь достаточно информации, предложи список отдельных навыков, которые можно создать из моих процессов. Пока не создавай файлы.
```

Отвечай на вопросы своими словами. Не нужно знать программирование.

## Шаг 2. Создай файл навыка

Выбери **одну конкретную задачу** из предложенного списка и отправь:

```text
Создай для задачи «[название задачи]» готовый навык Claude в формате SKILL.md.

Используй мои ответы из интервью. Опиши процесс пошагово, критерии качества, входные данные, типичные ошибки и то, что делать нельзя. Сделай инструкцию конкретной и применимой в работе, а не общей теорией.

Добавь в начало корректный YAML frontmatter с полями name и description, чтобы Claude понимал, когда применять этот навык. Название name — латиницей, в нижнем регистре, через дефисы.

Покажи полный текст SKILL.md и, если интерфейс позволяет, дай скачать файл. Не придумывай факты обо мне: если чего-то не хватает, сначала спроси.
```

**Важно:** если Claude выдаст просто текст, сохрани его в файл с точным названием `SKILL.md`. Для загрузки через интерфейс может понадобиться ZIP-архив с этим файлом внутри.

## Шаг 3. Установи навык

1. Открой **Claude → Settings → Capabilities → Skills** (названия разделов могут меняться).
2. Найди добавление собственного навыка / **Upload skill**.
3. Загрузи ZIP-архив с `SKILL.md` и включи навык, если потребуется.
4. Если такого раздела или кнопки нет, проверь доступность Skills в твоём тарифе и версии Claude.

Не загружай в публичные репозитории пароли, клиентские данные и другие секреты.

## Шаг 4. Проверь на реальной задаче

Напиши Claude:

```text
Используй мой навык «[название]» и выполни задачу: [опиши задачу]. Сначала скажи, какие исходные данные тебе нужны. В конце проверь результат по критериям качества из навыка.
```

Если результат не понравился, уточни инструкцию и обнови навык.

## Какие навыки можно создать?

- **Reels:** искать идеи, писать хуки и сценарии в твоём стиле.
- **Карусели:** превращать тему в структуру слайдов.
- **Посты:** соблюдать твой тон, структуру и запретные формулировки.
- **Работа с клиентами:** собирать брифы и проверять материалы по чек-листу.
- **Аналитика:** оформлять регулярные отчёты по твоему шаблону.

Лучше сделать **пять узких навыков для пяти разных задач**, чем один огромный файл «делай всё».

---

**Сохрани этот гайд**, чтобы настроить навыки один раз и возвращаться к ним в работе. Возможности установки зависят от версии и тарифа Claude.
