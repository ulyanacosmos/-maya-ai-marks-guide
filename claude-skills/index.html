Для начала

Что такое навык?

Это обычный файл SKILL.md, где словами описано, как выполнять конкретную задачу: что делать сначала, что потом и каким должен быть результат.

Вместо пяти отдельных агентов можно подготовить пять навыков для разных процессов: идеи Reels, сценарии, карусели, посты и анализ. Claude использует подходящий навык, когда он доступен и подходит к запросу.

01 / 04

Попроси Claude взять у тебя интервью

Не надо писать инструкции самостоятельно. Просто вставь этот промпт в чат с Claude и отвечай на вопросы обычными словами.

Возьми у меня подробное интервью, чтобы изучить мою сферу деятельности, рабочие задачи и процессы. Выясни, чем я занимаюсь, как организована моя работа, какие задачи я выполняю и по каким принципам принимаю решения. Задавай вопросы по одному, уточняй детали и постарайся максимально глубоко разобраться в моей работе. Обязательно узнай: — с чего начинается каждая задача; — какие шаги я выполняю и в каком порядке; — какие инструменты и материалы использую; — как понимаю, что результат готов; — какие ошибки возникают чаще всего; — что категорически нельзя делать. Когда информации будет достаточно, предложи 3–5 отдельных навыков для моих задач. Пока не создавай файлы.
02 / 04

Преврати ответы в готовый навык

Выбери одну задачу из списка, который предложил Claude, и отправь второй промпт.

На основе моего интервью создай готовый навык Claude для задачи «[НАЗВАНИЕ ЗАДАЧИ]». Подготовь полноценный файл SKILL.md с корректным YAML frontmatter: name (латиницей, маленькими буквами, через дефисы) и description (когда использовать навык). Внутри подробно опиши: 1. Когда применять навык. 2. Какие данные нужно запросить перед работой. 3. Пошаговый процесс. 4. Критерии хорошего результата. 5. Типичные ошибки и запреты. 6. Как проверить готовую работу. Используй только информацию из моего интервью. Если чего-то не хватает — сначала уточни. Покажи полный текст и дай скачать SKILL.md, если это возможно в интерфейсе.
Важно: навык — это не самостоятельный агент. Он помогает Claude следовать твоему процессу, но результаты всё равно нужно проверять.
03 / 04

Загрузи навык в Claude

  1. Сохрани файл с точным названием SKILL.md.
  2. Если потребуется, упакуй его в ZIP-архив.
  3. Открой Claude → Settings → Capabilities → Skills (названия пунктов могут отличаться).
  4. Найди загрузку своего навыка, добавь файл или архив и включи навык.

Если кнопки загрузки нет, проверь, поддерживаются ли пользовательские Skills в твоём тарифе и текущей версии Claude.

04 / 04

Проверь на реальной задаче

Теперь дай Claude настоящее задание — например, написать сценарий Reels по твоим правилам.

Используй мой навык «[НАЗВАНИЕ]» для задачи: [ОПИШИ ЗАДАЧУ]. Если не хватает исходных данных — сначала задай вопросы. В конце проверь результат по критериям качества из навыка.
